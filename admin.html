데이터베이스 연동 상태

별도의 유료 DB 없이 GitHub 레포지토리의 data/board.json 파일을 영구 보존 데이터베이스로 사용합니다.

연동 확인 중...
📌 Vercel 배포 시 GitHub 자동 커밋 영구 저장 설정법 (클릭하여 보기)
Vercel 대시보드 Project Settings → Environment Variables에 다음 3가지 환경변수를 등록하시면, 관리자에서 글을 쓸 때마다 GitHub 저장소로 자동 커밋되어 데이터가 영구 보존됩니다:
  • GITHUB_TOKEN: GitHub 개인 액세스 토큰 (Personal Access Token, repo 권한 필요)
  • GITHUB_OWNER: GitHub 계정명 또는 조직명 (예: your-github-id)
  • GITHUB_REPO: GitHub 레포지토리명 (예: your-realestate-repo)
  • ADMIN_PASSWORD: 관리자 비밀번호 (기본값: admin1234)
